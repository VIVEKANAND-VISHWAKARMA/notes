Privilege Escalation - Quick Checks
===================================

# Find SUID / SGID binaries (common privesc vector)
find / -type f -perm -04000 -ls 2>/dev/null

# Check what the current user may run as root
sudo -l

# Other quick wins
find / -perm -u=s -type f 2>/dev/null        # SUID binaries
getcap -r / 2>/dev/null                       # binaries with capabilities
cat /etc/crontab; ls -la /etc/cron.*          # scheduled tasks
uname -a; cat /etc/os-release                 # kernel/OS -> search exploits
id; sudo -l                                   # context + sudo rights
