Findings
--------
- Dev environment used weak, reused default credentials (value REDACTED).
- DC hostname pattern: dc01.<DOMAIN>.
- Backup server exposes rsync + SSH - worth checking for anonymous/weak auth.

Recon takeaway
--------------
1. Map every host and its services first (nmap -sV -A).
2. Look for the "easy" services: dev/docker hosts, backup servers, DB servers.
3. Never commit the recovered credentials themselves - only the technique.
